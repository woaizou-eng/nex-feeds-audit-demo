# NEX 信息流审核交互 Demo

公开产品交互演示，基于模拟数据，不连接真实审核服务。访问者无需登录；编辑结果保存在各自浏览器内，不会影响其他访问者或线上任务。

## 体验内容

- 信息流任务创建、机审／人审条件分配、规则项与算子引用。
- 任务中心提供一审迁入、新增数据来源、修改机审规则、调整优先级四个操作入口。
- 新建任务可单选一个数据集或一个数据集包；包内维护来源，关联任务同步看到成员变化。任务内优先级可单独设置。
- 每个机审条件分支独立配置题目、算子与规则项；共享算子可查看引用影响。
- 分组、流程及业务／订正数据分类使用标签，标签不决定送审范围。
- 报表收拢为信息流一二审、择优数据看板两个入口，原有报表与积木配置保留。
- 筛选项逐行展示、常用项前置、名称／说明／关键词／ID 模糊搜索。
- 任务数据列表含料理、咖啡、海边旅行三条演示素材；视频可直接播放，封面和组图可切换。
- 免审、模板、标签、报表及导出等交互。

高频排序以当前流程在该浏览器内的选择次数计算。首次使用展示预置常用示例，不代表真实生产使用频率。

本页仍含尚未完成的演示模块，不作为 NEX 平台能力或生产验收结论。组件管理、定向质检入口已隐藏。

数据集包只演示来源成员联动，不重跑已有记录；线上在途处理、重新送审执行位置、报表权限隔离及审核理由维护归属仍需确认。既有浏览器配置继续保留。

视频与图片已内嵌页面，素材来源和授权见 [MEDIA-SOURCES.md](MEDIA-SOURCES.md)。页面中的账号名、标题和人员名为演示数据；流程与规则标识保留为迁移方案示例。

# NEX 信息流审核交互 Demo

公开产品交互演示，基于模拟数据，不连接真实审核服务。访问者无需登录；编辑结果保存在各自浏览器内，不会影响其他访问者或线上任务。

## 体验内容

- 信息流任务创建、机审／人审条件分配、规则项与算子引用。
- 新增“信息流一审去劣”完整假数据示例：4 个 API 数据集、10 条共享送审样本，分为图文双人审和视频单人审两个任务。
- 示例可实际演练机审拒绝、免机审、免人审、人工标注、双人分歧复核、质检与模拟回传；最终结果可通过原导出入口导出。算子使用预置假结果，回传只生成本地演示报文。
- 任务中心提供一审迁入、新增数据来源、修改机审规则、调整优先级四个操作入口。
- 数据集独立创建，在标签中按分组选择所属流程（单选），并配置其他标签和数字优先级；创建任务共用同一标签层级，实际关联流程与分组。审核对象默认内容。
- 优先级可直接修改并自动保存到数据集，关联任务同步使用，不新增任务内覆盖值；不再设置“管理／统一管理”列。
- 建任务的数据集区域按 NEX 布局展示“从已有数据中导入／新建数据集”、右侧优先级及“类型＋名称或 ID”选择框；流程数据集与多数据集任务展示各成员优先级。
- 任务支持普通数据集和流程数据集，均提供新建和选择已有入口；流程数据集按所属流程动态汇总独立数据集，新增成员后自动纳入。任务创建不额外增加圈选环节，数据处理条件在原机审、人审条件分配中配置。
- 机审算力直接展示配置页，默认审核对象为内容，支持保存、撤销和四档试算。任务流程中不绑定算力策略；条件使用模拟数据，不执行资源调度。
- 每个机审条件分支独立配置题目、算子与规则项；共享算子可查看引用影响。
- 任务与数据集共用分类标签选择器。普通标签可多选，所属流程单选；流程选择同步决定可选数据集范围。
- API 数据集的“已审可重新送审”与“业务数据／订正数据”同排展示；ODPS、本地上传不展示这两项。
- 驾驶舱保留“流转监控”“审核质量分析”两个入口；流转监控分“一二审／择优”两个 tab，保留实时、历史、漏斗、饼图与积木配置。原审核监控、标注监控入口移除。
- 筛选项逐行展示、常用项前置、名称／说明／关键词／ID 模糊搜索。
- 任务数据列表含料理、咖啡、海边旅行三条演示素材；视频可直接播放，封面和组图可切换。
- 数据列表前置 BIZ 卡片的媒体、标题、内容 ID、账号、时间及结果；同步 32 个 BIZ 筛选字段，增加 2.0／3.0／4.0 来源列和筛选。缺少来源的历史记录标待确认。
- 全部、机审、人审量级分别展示待派单、已取消、待审核、审核通过、审核拒绝；点击数字可筛选，环节量级可重叠。
- 勾选后可批量修改已生效审核结果，展示影响条数并要求填写理由；保留旧结果，更新本地导出与模拟回传。驳回重审会归档原结果，重新审核后发布新结果。
- 数据分析默认当前任务；选分组或流程后汇总其下任务，区分去重送审记录和任务记录，保留近 7 天趋势。
- 免机审、特征计算、人工标注均支持开关；关闭保留配置，校验和演练遵循开关，无有效结论时不会自动通过。
- 免审、模板、标签、报表及导出等交互。

高频排序以当前流程在该浏览器内的选择次数计算。首次使用展示预置常用示例，不代表真实生产使用频率。

本页仍含尚未完成的演示模块，不作为 NEX 平台能力或生产验收结论。组件管理、定向质检入口已隐藏。

新增数据集挂靠流程后，演示流程数据集共享，不重跑已有记录；线上在途处理、重新送审执行位置、报表权限隔离及审核理由维护归属仍需确认。既有浏览器配置继续保留。

旧任务的优先级配置保留。若同一来源在不同任务中的历史值冲突，统一配置前提示核对，不擅自选择其中一个值。

视频与图片已内嵌页面，素材来源和授权见 [MEDIA-SOURCES.md](MEDIA-SOURCES.md)。页面中的账号名、标题和人员名为演示数据；流程与规则标识保留为迁移方案示例。

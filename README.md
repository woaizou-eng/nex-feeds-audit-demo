# NEX 信息流审核交互 Demo

公开产品交互演示，基于模拟数据，不连接真实审核服务。访问者无需登录；编辑结果保存在各自浏览器内，不会影响其他访问者或线上任务。

## 体验内容

- 信息流任务创建、机审／人审条件分配、规则项与算子引用。
- 任务中心提供一审迁入、新增数据来源、修改机审规则、调整优先级四个操作入口。
- 数据集独立创建，配置标签、所属流程和数字优先级；数据集列表展示所属流程及优先级。
- 每个数据集统一维护优先级，引用它的任务只读展示并可跳转调整，不再设置另一套任务内覆盖值。
- 任务支持普通数据集和流程数据集。普通数据集单选；流程数据集动态引用所属流程下的独立数据集，新增数据集挂靠流程后自动纳入，无需逐任务追加。任务圈选与机审、人审条件分配分别配置。
- 机审算力配置使用一到四档的条件策略与兜底档位，任务引用策略并查看演练样本命中结果。页面结构参考 BIZ，条件使用模拟数据，不执行真实资源调度。未核实的多档命中裁定、来源档位映射单独标注。
- 每个机审条件分支独立配置题目、算子与规则项；共享算子可查看引用影响。
- 任务与数据集共用分类下拉选择和新建标签，支持按类型浏览、搜索、多选；业务数据与订正数据二选一。新建标签的类型会保存。标签不改变送审范围、模板或审核配置。
- 报表保留信息流一二审、择优数据看板两个入口；审核监控与标注监控融合为作业监控，重复指标合并，原积木配置可查看和导入。
- 筛选项逐行展示、常用项前置、名称／说明／关键词／ID 模糊搜索。
- 任务数据列表含料理、咖啡、海边旅行三条演示素材；视频可直接播放，封面和组图可切换。
- 免审、模板、标签、报表及导出等交互。

高频排序以当前流程在该浏览器内的选择次数计算。首次使用展示预置常用示例，不代表真实生产使用频率。

本页仍含尚未完成的演示模块，不作为 NEX 平台能力或生产验收结论。组件管理、定向质检入口已隐藏。

新增数据集挂靠流程后，演示流程数据集共享及任务圈选联动，不重跑已有记录；线上在途处理、重新送审执行位置、报表权限隔离及审核理由维护归属仍需确认。既有浏览器配置继续保留。

旧任务的优先级配置保留。若同一来源在不同任务中的历史值冲突，统一配置前提示核对，不擅自选择其中一个值。

视频与图片已内嵌页面，素材来源和授权见 [MEDIA-SOURCES.md](MEDIA-SOURCES.md)。页面中的账号名、标题和人员名为演示数据；流程与规则标识保留为迁移方案示例。

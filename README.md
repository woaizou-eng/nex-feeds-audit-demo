# NEX 信息流审核交互 Demo

公开产品交互演示，基于模拟数据，不连接真实审核服务。访问者无需登录；编辑结果保存在各自浏览器内，不会影响其他访问者或线上任务。

## 体验内容

- 按 Roadmap 保留流程映射，本轮预置 8 个流程 × 图文／视频，共 16 个 NEX 任务；2026-11-16 回读的 259 条 BIZ 子任务（232 条在用、27 条暂停）收在对应任务内部。暂停配置保持停用，可查看、编辑和恢复。
- 算子管理新增 50 个内容规则项、36 个已配置组合算子，覆盖一二审、择优和广告场景；任务已关联流程数据集、模板、条件分配、算子和成员配置。任务清单来自 BIZ 回读，条件、阈值、人员和样本为模拟数据。
- 预置任务提供可操作样本：105317 图文保留双人标注；择优通用结果为 S/A/B/C/D。旧版重复示例从主列表移入浏览器内备份，用户自行创建或复制的任务保留。
- 广告素材审核 115543 按用户确认本轮暂不预置，流程目录与模板库均标为“本轮暂不预置”；这只调整本轮 Demo 范围，不改变实际迁移计划。另有两条免审拒绝来源未回显模板，在图文／视频任务内共用其来源 ID 并标明未核实；不额外建立第三种素材任务。

- 信息流任务创建、机审／人审条件分配、规则项与算子引用。
- 任务列表提供“分组／平铺”切换，保留 16 个任务。分组模式下可展开审核节点及节点内子任务；平铺模式仅展示任务，不显示节点和子任务；展示来源 ID、优先级、条件、模板或免审结果及状态，可直接打开配置编辑。独立免审只展示免审节点，免机审、免人审留在对应节点内。初始推荐一审 10 个、推荐二审 2 个、择优 4 个任务。
- 独立“免审”节点提供“免机审／免人审／全部免审”范围单选，节点内各分配条件共用所选范围；结果和理由字段、任务列表及控制台随范围展示。独立免审与机审、标注、质检互斥，无需模板；常规节点内的免机审／免人审固定类型，不重复选择。
- 本次只增加免审范围配置，执行仍沿用原演示逻辑：命中后写入最终审核结果并结束当前任务，未命中或缺结果时保留待处理。范围选择不自动改变结果生效口径；阶段结果输出与跨任务承接尚未发布。
- 106236、106224 的图文／视频任务预置为独立免审；106224 同结果的来源合并配置并保留原 BIZ 任务 ID。免审结果支持原有导出入口。算子、审核与回传仅使用本地演示数据。
- 任务中心提供一审迁入、新增数据来源、修改机审规则、调整优先级四个操作入口。
- 数据集、任务创建及编辑中，“所属分组”“所属流程”独立同排展示，均为单选；先选分组再选该组的流程，数据集选择限于当前流程。其他标签单独多选或新建。已关联任务的数据集、有数据的任务保持原归属。审核对象默认内容。
- 数据集业务入口默认业务数据集，无当前业务归属的通用数据集不展示；旧业务来源按流程归属保留。3.0 档位＋优先级到 4.0 的映射标为待确认，不编造换算规则，当前手动优先级继续生效。
- 优先级可直接修改并自动保存到数据集，关联任务同步使用，不新增任务内覆盖值；不再设置“管理／统一管理”列。
- 建任务的数据集区域按 NEX 布局展示“从已有数据中导入／新建数据集”、右侧优先级及“类型＋名称或 ID”选择框；流程数据集与多数据集任务展示各成员优先级。
- 任务支持普通数据集和流程数据集，均提供新建和选择已有入口；流程数据集按所属流程动态汇总独立数据集，新增成员后自动纳入。任务创建不额外增加圈选环节，数据处理条件在原机审、人审条件分配中配置。
- 机审算力直接展示配置页，默认审核对象为内容，支持保存、撤销和四档试算。任务流程中不绑定算力策略；条件使用模拟数据，不执行资源调度。
- 每个机审条件分支独立配置题目、算子与规则项；共享算子可查看精确的任务、节点、条件分配与题目引用。已引用算子的修改、启停及取消关联需先提交本地模拟审批，通过后生效，待审和驳回保留原配置；未关联草稿可直接保存。新增“审批演示”入口与演示辅助算子；审批管理的“算子变更”可查看前后配置、影响任务及审批状态。路由条件引用需回到节点完整修改条件；移除最后一个必要引用需先配置替代。
- 任务与数据集共用分类标签选择器，仅承载其他分类；分组、流程不再放在标签中选择，历史自建普通标签保留。
- API 数据集的“已审可重新送审”与“业务数据／订正数据”同排展示；ODPS、本地上传不展示这两项。
- 驾驶舱保留“流转监控”“审核质量分析”两个入口；流转监控分“一二审／择优”两个 tab，保留实时、历史、原有指标、趋势和明细。移除 Demo 额外添加的“审核流转漏斗”“择优等级分布”两张默认卡片，保留 BIZ 对照的内容质量概况和规则命中分布。NEX 漏斗／饼图积木仍可手动配置，用户自行添加的其他卡片保留。原审核监控、标注监控入口移除。
- 筛选项逐行展示、常用项前置、名称／说明／关键词／ID 模糊搜索。数据列表统一通过“添加筛选项”选择字段与规则条件，不再单独展示内容规则／算子入口。
- 任务数据列表含料理、咖啡、海边旅行三条演示素材；视频可直接播放；图片组图首张展示封面，相同图片去重，可原位切换与悬停放大。
- 任务数据默认卡片展示，可切换平铺，共用筛选、排序、勾选和批量修改结果。查看详情或进入审核使用参照 BIZ 3.0 的沉浸页：素材、参考信息与题目同屏，图片题按封面／图片分别填写；一二审通过／不通过，择优 S/A/B/C/D。双人独立提交后比对，差异进入复核，质检不合格可继续复核。
- 送审数据集操作新增“数据 case”，任务中心新增“数据查询”，分组增加“查看数据”。同一页面按分组／流程／数据集／任务筛选，支持 BIZ 字段及送审时规则结果检索。按数据集＋送审记录聚合，跨任务结果逐条保留，同内容重新送审另列一条，池内未进入任务的数据仍可查看。缺少稳定送审 ID 的历史数据仅在可核对到同一池快照时合并。
- “查看跨任务示例”提供独立查询样例：同次送审进入两个任务、同内容再次送审、未进入任务；不改变原 16 个任务配置。跨任务汇总只读，审核及结果修改需进入具体任务。
- 数据列表前置 BIZ 卡片的媒体、标题、内容 ID、账号、时间及结果；同步 32 个 BIZ 筛选字段，增加 2.0／3.0／4.0 来源列和筛选。缺少来源的历史记录标待确认。
- 状态统计并入顶部原有的数据总量、机审进度、标注进度，保留质检进度；不再另设量级卡片。顶部统计全任务，点击状态数字可查看对应记录。
- 勾选后可批量修改已生效审核结果，展示影响条数并要求填写理由；保留旧结果，更新本地导出与模拟回传。驳回重审会归档原结果，重新审核后发布新结果。
- 数据分析默认当前任务；选分组或流程后汇总其下任务，区分去重送审记录和任务记录，保留近 7 天趋势。
- 免机审、特征计算、人工标注均支持开关；关闭保留配置，校验和演练遵循开关，无有效结论时不会自动通过。
- 免审、模板、标签、报表及导出等交互。

高频排序以当前流程在该浏览器内的选择次数计算。首次使用展示预置常用示例，不代表真实生产使用频率。

本页仍含尚未完成的演示模块，不作为 NEX 平台能力或生产验收结论。组件管理、定向质检入口已隐藏。

新增数据集挂靠流程后，演示流程数据集共享，不重跑已有记录；线上在途处理、重新送审执行位置、报表权限隔离及审核理由维护归属仍需确认。既有浏览器配置继续保留。

旧任务的优先级配置保留。若同一来源在不同任务中的历史值冲突，统一配置前提示核对，不擅自选择其中一个值。

视频与图片已内嵌页面，素材来源和授权见 [MEDIA-SOURCES.md](MEDIA-SOURCES.md)。页面中的账号名、标题和人员名为演示数据；流程与规则标识保留为迁移方案示例。
